# 已知局限性

本文档描述 HiFiVar 发布候选版本 0.1.0rc4 及其基准测试结果的已知局限性。

## 1. 基准测试范围局限性

### 单一数据集

所有基准测试使用单一的 HG002 PacBio HiFi CCS 11kb 数据集。结果可能不适用于其他样本、祖先或测序技术。

### 一种配置

基准测试使用一种特定配置：
- PacBio HiFi CCS 11kb
- GRCh38 参考基因组
- chr1–chr22 置信区域（小变异）
- CMRG 具有挑战性的医学相关基因（SV）

不同的配置可能产生不同的结果。

### CMRG 不是全基因组

CMRG 读段 SV 基准测试仅覆盖**具有挑战性的医学相关基因**（250 条真相记录，经过大小过滤后 216 条有资格）。它**不是**全基因组 SV 真相基准测试。全基因组 GRCh38 读段 SV 基准测试：NOT_AVAILABLE。

### 没有全基因组 SV 真相

没有完整的、经过验证的全基因组 GRCh38 SV 真相数据集用于全面的 SV 调用评估。CMRG 资源覆盖特定的医学相关区域子集。

## 2. 工具和环境局限性

### 传统 hap.py 环境

hap.py 基准测试工具（0.3.15）运行在 Python 2.7.15 上，这是传统环境。未来版本的 hap.py 可能产生不同的结果。

### 外部工具依赖

HiFiVar 编排外部生物信息学工具。每个工具都有其自己的：
- 版本特定行为
- 容器/Conda 环境要求
- 参考基因组和数据库依赖
- 资源要求

不同的工具版本可能产生不同的结果。

### 容器和部署

一些可选的工作流分支需要单独的容器或 Conda 部署。HiFiVar 核心包不捆绑外部调用器二进制文件、参考基因组或数据库。

## 3. 技术局限性

### DeepVariant 分片数

DeepVariant WGS 运行使用 4 个分片而不是 8 个，因进程/线程资源限制（ulimit -u=4096）。分片数影响并行执行但不影响科学算法。

### 硬剪切移除

Sawfish 和 pbsv 需要无硬剪切的 BAM 输入。硬剪切移除预处理是工具兼容性工件，可能略微改变比对与原始结果。

### 没有统一的 FASTQ 到 VCF 管道

当前发布候选版本不暴露单个统一的 `hifivar run` 命令或 Snakemake 比对规则。FASTQ 比对必须在进入变异调用管道之前单独执行。

## 4. 解释局限性

### 支持指标，不是生物学真相

TP/FP/FN 计数和派生指标（精确度、召回率、F1）表示调用器输出和真相数据集之间的计算一致性。它们不构成生物学真相或临床解释。

### 不提供临床声明

基准测试指标不意味着：
- 临床有效性
- 诊断实用性
- 生物学意义
- 致病性
- 医学可操作性

### 配置特定

所有结果特定于使用的确切工具版本、参数、参考基因组构建和真相数据集。不应在没有重新基准测试的情况下推广到其他配置。

### 调用器支持不是真相

支持变异的调用器数量仅是描述性证据。它不建立生物学真相、置信度或临床意义。

### 注释不是置信度

功能注释分数（例如来自 ANNOVAR、VEP 或 AlphaGenome）不代表变异调用置信度或真相状态。

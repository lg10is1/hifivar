# SV depth study template

[简体中文](README.zh-CN.md)

This is a schema template for new RC5 source, not an executed benchmark. Replace all example data/tool paths with existing validated files; then run hifivar --dry-run benchmark sv-depth before executing any caller. The 12units represent4nominalsamplinglabels×3technicalreplicates; record actual measured depths and shared full-input read set. See ../../docs/sv_depth_study.md. The actual study's truth/BED/version and fixed caller/comparator settings must be frozen before calling. No benchmark metrics are bundled here.

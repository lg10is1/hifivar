# AlphaGenome explicit selection template

[简体中文](README.zh-CN.md)

New RC5 source only. Fill selected_variants.tsv with actual chosen records and an existing annotation provenance file; the header-only template intentionally cannot execute. No illustrative allele is presented as an HG002 call. Provide GRCh38 FASTA+FAI, use the dry-run first, and consult ../../docs/alphagenome.md for the local REF/full-context check, environment credential and explicit data-sharing/network gates. Never put a literal key into these files. This template does not make a remote API request.

## English

HiFiVar 0.1.0rc5 is a research prerelease for Linux and HPC. The main launcher accepts indexed BAM and can prepare alignments from configured FASTQ or native uBAM inputs. Optional branches cover small variants, structural variants, tandem repeats, joint phasing and explicitly sourced downstream analysis. Provision the external executables, indexes and reference resources for each enabled branch.

- Download the wheel and SHA256SUMS from this page, verify the digest and follow the installation guide.
- Single-sample and batch workflows are documented. Validate the configuration and inspect a dry run before executing the analysis.
- Previous development builds with the same version string have their own source manifests, checksums and validation records. See the capability guide for the scope of benchmark and native-tool evidence.
